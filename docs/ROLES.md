# Роли на сайте Magnat Trade

Иерархия: **менеджер** → **оптовый покупатель** → **обычный (розница)**. Суперпользователь Django (`is_superuser`) в бизнес-логике не фигурирует.

## 1. Обычный пользователь (`user_type = retail`)

- В каталоге и корзине видит **розничные** цены (`retail_price`).
- Может оформлять заказы **с регистрацией** или **без** (гость — только розница).
- После регистрации может **подать заявку** на опт: профиль → блок «Оптовые цены» → текст заявки → отправка. Пока заявка в статусе «На рассмотрении», повторно отправить нельзя.

## 2. Оптовый пользователь (`user_type = wholesale`)

- Видит **оптовые** цены (`wholesale_price`) в каталоге, карточке товара, корзине и при оформлении заказа (см. `shop/pricing.py`, `html_catalog_order`).
- Роль **не назначается при регистрации**: на странице `/sign-up/` нет выбора типа цены; API (`/api/register/`) всегда создаёт пользователя с типом **розница** и первичной синхронизацией контрагента в 1С (`register_site_user_in_onec`). После **одобрения опта** менеджером вызывается повторная отправка в 1С с `price_type: wholesale` (`sync_site_user_counterparty_in_onec`). То же при смене розница/опт в панели менеджера.

## 3. Менеджер и доступ к панели заявок

- **Панель** `/profile/manager/` (заявки на опт, цены, категории, пользователи) доступна, если выполняется **хотя бы одно**:
  - `user_type = manager`, или
  - **«Статус персонала»** (`is_staff`) в Django-админке, или
  - суперпользователь (`is_superuser`).
- Отдельно: бизнес-роль «менеджер» в каталоге (цены как у розницы) по-прежнему задаётся полем **«Тип пользователя» → Менеджер**.
- В профиле видит ссылку **«Панель менеджера»** (`/profile/manager/`).
- Полномочия:
  1. **Заявки на опт** — список ожидающих, одобрение (пользователь → `wholesale`) или отказ с примечанием.
  2. **Цены товаров** — поиск по каталогу 1С, правка `retail_price` и `wholesale_price`.
  3. **Категории** — создание (с опциональным родителем), переименование, вкл/выкл, удаление (если нет привязанных товаров — иначе `ProtectedError`).
  4. **Пользователи** — смена типа `retail` / `opt`, удаление (не менеджеры и не суперпользователи; нельзя удалить себя).

Менеджер на витрине при покупке рассчитывается как **розница** (не опт), если смотрит каталог как покупатель.

## Технические файлы

| Область | Файлы |
|--------|--------|
| Модель ролей и заявки | `users/models.py` (`User.user_type`, `WholesaleUpgradeRequest`) |
| Цены для текущего пользователя | `shop/pricing.py` |
| Каталог 1С | `shop/catalog_display.py` (`CatalogProductDisplay(..., user=request.user)`) |
| Регистрация только розница | `shop/api/auth.py`, `shop/templates/shop/sign-up.html` |
| Синхронизация контрагента 1С | `integrations/services/onec_registration.py` |
| Панель менеджера | `shop/manager_views.py`, `shop/templates/shop/manager_dashboard.html` |
| Заявка из профиля | `shop/views.py` → `user_profile` |
